# COMMERCIAL

This document describes the commercial boundary for Sydeso.

## Purpose

The public core repository provides source-available self-hostable capabilities.

Commercial Sydeso offerings may include additional private modules and hosted services.

## Commercial/Private Areas

Potential private/commercial areas include:

- Hosted cloud operations
- Managed runner provisioning
- Billing and plan entitlements
- Enterprise identity/compliance modules
- Advanced analytics and reporting
- Commercial marketplace capabilities
- Private deployment orchestration

## Public Contributor Note

Contributing to this repository improves the public core.

Commercial/private modules are maintained separately and are not required for public contribution.

## Licensing

The public core license is Business Source License 1.1 as defined in `LICENSE`.

Commercial terms for hosted offerings are separate.

## Contact

For commercial licensing or hosted offerings, open a GitHub Discussion or contact the project owner through repository channels.
